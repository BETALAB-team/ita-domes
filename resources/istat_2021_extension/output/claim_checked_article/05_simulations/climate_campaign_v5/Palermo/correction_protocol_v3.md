# Pre-run correction protocol v3 — single state commit per hour

Independent reviewer 01 reproduced all five v1 outputs byte-identically and found full-step residual failures at 898, 846 and 766 seeded/early/late hours, with maximum absolute node residuals around 9.26–9.65 kW. The recursive `ThermalZone.solve_timestep` commits state inside a recursive mode change and then advances or overwrites the same hour in an outer frame. The earlier network-algebra and repeat checks did not detect this dispatcher defect. All 25 original annual outputs are quarantined and may not support scientific findings.

Correction scope: a local adapter `04_analysis/single_commit_1c.py` reuses EUReCA's unchanged pure `sensible_balance_1C` algebra and all unchanged preprocessing, weather, geometry, gains, infiltration and source-derived temperature schedules. It computes a free-floating trial from old air/mass states; if that trial crosses a temperature band, a constrained trial uses the same unchanged old states. It then commits only the selected air/mass solution once. The previous operating flag cannot force a second physical advance. No external source or environment is changed, no calibration occurs, and no scenario definition changes.

The adapter explicitly supports this study's zero mechanical/natural ventilation and zero internal latent-gain case. It retains ideal unlimited sensible heating/cooling, with the same 50°C upper bound so cooling should remain inactive. Moisture is uncoupled from the sensible network and is not advanced or reported; no latent/HVAC/final-energy claim follows. The correction is not a general replacement for EUReCA's complete systems dispatcher.

Before any corrected annual run, deterministic off→heating, heating→off, steady-off, continuing-heating and off→cooling trials must preserve old state during candidate calculations, select the expected mode and close each node balance within 1e-6 W. Original analytical equilibrium/steady-state tests remain separate checks.

Each annual output now exports prior/current air/mass states, current surface temperature, load-node forcing, infiltration conductance and delivered load split. Static network parameters and timestep are saved. An independent standard-library postprocessor must recompute every hourly air, surface and mass residual from the saved old/current states and forcing; all absolute residuals must be ≤1e-6 W. This is the corrected full-step gate, in addition to v2 finite/calendar, block-count, setpoint, zero-cooling, exact-repeat and warm-up checks. It verifies numerical conservation, not empirical predictive accuracy.

Chronology: run the five corrected official-weather Padova cases first, then execute the independent full annual balance/integration checks and verify its transition gate. Only after those pass may the remaining Bolzano, Roma and Palermo coordinate cases execute. All four retain three primary schedules plus one repeated seeded case and one 336 h warm-up seeded case, giving 20 corrected annual runs. No duplicate Padova pilot is needed. Freeze config, design, original protocol, v2 addendum, this correction protocol, adapter source, correction module, source-package hashes and weather metadata before each site begins.

Primary outcomes stay annual useful sensible heating demand and maximum hourly sensible heating load. All summaries, paired contrasts and the explicitly post-hoc setpoint partition must be recomputed from v3 files. V1/v2 differences are diagnostic evidence of the implementation defect, not extra household or climate samples. Current results remain pending independent review of this correction and its exported residual checks.
