## What would make the extension substantive

1. Recovered, auditable implementation of all relevant published user classes, not labels appended to the previous single respondent.
2. Explicit alternatives: class-specific inputs, a declared pooled/default representation, and a small schedule/gain ablation if both channels change. The exact factorial design belongs to the methods owner.
3. Separate response distributions or well-labelled deterministic class contrasts from population totals; represent assignment probabilities only when supported.
4. Matched physical/weather accounting and reported uncertainty, including class-to-dwelling support and schedule construction.
5. Independent benchmark/empirical evaluation only where its inputs, time/energy boundary and separation from fitting are documented.

The literature allows this as a focused application and evidence audit. It does not establish a broad methodological first. A null class contrast, failure of a pooled approximation, or inability to validate a household assignment can each be reported honestly; no beneficial result is assumed.
