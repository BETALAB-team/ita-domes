# Post hoc v2 peak-context diagnostic plan

This diagnostic is introduced after independent review 05 (R5-02), which reported concentration of the new Bolzano individual annual maxima at the imposed seasonal restart. The review's reported counts were known before this independent author-side recomputation. This is post hoc descriptive context, not a preregistered endpoint, sensitivity run, causal test or alternate annual maximum.

Read all 144 scientific raw hourly CSVs directly: 36 profiles at each of Padova, Bolzano, Roma and Palermo. Each site's profile roles are 32 held-out respondents and four shared real components, from the unchanged frozen v2 role manifest. Exclude all eight repeat/warm-up checks from this diagnostic. Hash every input file, verify complete ordered model hours 0–8759 and finite loads/context fields, and independently find the maximum of nonnegative sensible heating load for each scientific file. Do not read the producer's endpoint summaries or use earlier checker/analysis functions to find maxima.

For each file preserve every hour whose parsed load equals its positive maximum exactly, plus the deterministic first such hour and its setpoint, old-air and outdoor temperatures. Report both first-maximum and any-tied-maximum restart classifications; record tie counts so they cannot be hidden. If a whole file has zero heating, preserve the endpoint zero and mark its positive-maximum context absent rather than turning 8760 zero hours into physical peaks. All original denominator records remain in the descriptive cohort counts.

The fixed study season resumes at model hour 6912 (day index 288, 16 October 2023 at 00:00 fixed UTC+1); its first day is hours 6912–6935 inclusive. Count maxima on that day and exactly at hour 6912 separately, with explicit denominators of 32 test respondents and four components at every site. Also identify January first maxima using hours 0–743. This is model calendar context, not evidence of local regulatory operation, equipment sizing or causal attribution to restart. No annual maximum, simulation input, frozen primary metric or prior result table is changed.
