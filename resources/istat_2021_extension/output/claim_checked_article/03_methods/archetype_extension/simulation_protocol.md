## Question, estimands and comparator

How faithfully do four demographic-conditioned real representative input profiles reproduce held-out detailed-input EUReCA heating outcomes, compared with one pooled real representative input, when the dwelling and weather are controlled? This is input-compression fidelity against the same model with more detailed respondent inputs. Detailed-input outputs are not measured ground truth. A negative paired absolute-deviation difference favors the four-profile representation within this experiment; it does not establish actual consumption accuracy or demographic causal effects.

The four-versus-one capacity difference is intentional and must be prominent. It prevents a claim that demographic grouping is superior independently of prototype count. A pooled mixture of group output means is only bookkeeping and is not the comparator or evidence of benefit. No output-fitted model, energy-based clustering, calibration or prototype tuning is permitted.

Primary endpoints remain annual useful sensible space-heating demand (kWh) and maximum hourly sensible heating load (kW). For held-out household i at site s, obtain detailed reference y_i,s, group-medoid prediction p_g(i),s and pooled-medoid prediction p_pool,s. Report signed deviations, absolute deviations and the paired difference |p_g−y_i|−|p_pool−y_i|. Report stratification-reweighted mean absolute and signed deviations overall and by archetype, plus all individual values. RMSE may be descriptive with an explicit weighted-squared-deviation formula. No measurement-based accuracy, savings or superiority claim follows.

## Split and input-only prototype selection

1. Construct four source-control branches from the compact source rule: 22/11, 22/19, 24/13 and 24/21°C on/off values. Timer/valve/retrofit-control indicators select the assumed setback; fireplace indicators add 2 K for central/individual heat. Those are the actual inspected source rules, not reported temperatures. All four branches have adequate nonzero support in each eligible group.
2. Sort group IDs, then branches numerically by on/off temperature, and candidate household IDs ascending. Use NumPy Generator(PCG64(20261020)). Draw two IDs without replacement in each group×control branch. This fixes 32 test IDs, eight per group. No input/outcome-driven replacement or post-run expansion is allowed.
3. All remaining 13,592 eligible records form training data. Test IDs never enter profile selection. Construct each training record's actual source-rule first-day 24-hour temperature vector, including its original ID seed and respondent control/fireplace branch; the fixed climate-E off-season is common and zero.
4. Within each demographic training group, compute its unweighted 24-hour input centroid. Select an actual training respondent with minimum squared Euclidean temperature distance to that centroid. This is equivalent to minimizing total squared input distance to all training vectors. Use tolerance 1e-10 K² for numerical ties, then smallest survey ID. The centroid is used only for selection and is never simulated. It must not be called a measured or representative group-mean schedule.
5. Select one pooled training medoid by the same rule from all training records. The five prototype roles may share an identical complete profile; preserve roles and deduplicate only thermal executions transparently.

Within source stratum (g,b), inclusion probability is 2/N_gb. Each test record's within-group descriptive weight is N_gb/(2N_g); overall empirical-domain weight is N_gb/(2N). Each normalization sums to one over its target cohort. Equal-group macro summaries, if shown, use a separate named weight 1/(4×2) times N_gb/N_g. These weights describe the frozen stratified evaluation and do not create survey-population confidence intervals. Prototype fitting depends on the split, so do not overstate these descriptive losses as unbiased out-of-sample national estimators.

The holdout is small. Show individual detailed-input outcomes, weighted group spread and branch support, not stable population quantiles or design-based uncertainty. No selected respondent is called a representative person, a city household, or an exact published user-archetype schedule.

## Controlled simulation bridge

Only actual reported heating block hours and the respondent-conditioned inspected source mapping differ. Keep the same v5 80 m² physical dwelling, envelope, constant internal gains, fixed 0.3 ACH, ideal sensible heating, climate-E season, upper cooling limit, hourly calendar and four already selected coordinate TMYs. Demographic ages, education and household size do not automatically generate occupancy/gain curves. This implements the joint heating/control component of user archetypes while holding physical-building and internal-gain effects fixed. It cannot attribute between-group differences separately to durations, control devices or fireplace assumptions without a new ablation; this limitation must be explicit.

Use source-seeded contiguous within-band placement only. The reviewed v5 early/late study remains linked timing-ambiguity evidence; do not multiply this campaign by those alternatives. Keep the corrected single-commit, IR-derived annual-mean sky and independent-surface preprocessing modules and all their limitations. No external source/environment mutation, latent/final-energy conversion or new system model is introduced.

At most 37 input roles (32 held-out detailed inputs, four group medoids, one pooled medoid) × four climates = 148 primary role cases. Deduplicate identical full 8,760-value lower-temperature arrays by exact little-endian float64 SHA256, preserving household/prototype roles and weights in a role-to-execution table. Add one repeated pooled-profile run and one 336 h warm-up pooled-profile run per site (eight checks). Expected unique annual execution count is determined by the frozen input manifest before outcomes, never by results. An optional separately identified fresh-destination replay tests reproduction and is not another sample. Pilot estimate is roughly 2–4 minutes for annual loops plus shared weather/forcing preprocessing, with bounded raw outputs under the new campaign root.
