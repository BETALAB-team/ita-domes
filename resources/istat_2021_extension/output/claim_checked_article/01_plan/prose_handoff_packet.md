# Separate prose-author handoff

This packet is preparatory. It authorizes no prose until the orchestrator records four complete cycles, final Astra closure and a frozen final claim snapshot. Read the human request in `00_context/user_request.md`, especially stages F–G.

Required role/model: a new separate `gpt-6.1-sol` agent. Own `08_manuscript` and `09_figures/figure_briefs.md` only. Do not change claims, reviews, source registries, simulations or rendered figures. The separate visualization agent owns figure outputs. No generative-image tools.

Scientific authority after the gate: `06_claim_drafts/article_claims_final.md`, matching final version ledger and `07_reviews/final_closure.md`; final issue register; verified external and local source ledgers. Current numerical files are v5 only. Earlier runs are quarantined. The claim checker remains the scientific source of truth. Review is not empirical validation.

Write coherent restrained English scientific prose in `08_manuscript/article_first_draft.md`. Use a provisional conventional article structure, with title, abstract, introduction, methods, results, discussion, limitations, conclusions and verified references as useful. No invented journal requirements or authorship. State its incomplete validation status visibly. Keep the actual contribution modest: one assumed dwelling, one selected unweighted response, three constructed high-setpoint placements, four coordinate weather exposures. No observed hourly schedule, population effect, improved prediction, measured accuracy, first-method novelty, savings, equipment sizing or climate-variable causal mechanism.

Use only facts, numbers, interpretations and references supported by final reviewed claims. If a substantive new assertion is needed, return it to the claim owner before using it. Do not import old numerical results, source correction narratives as broad package findings, unsupported climate descriptors or an empirical comparison. Preserve useful sensible heat versus final energy; high-setpoint hours versus actual heater runtime; primary versus post-hoc diagnostics; same-site seeded denominators; one physical case versus repeat/warm-up/replay counts. Keep annual-mean sky, solar-time, fixed season and Bolzano season-onset peak limitations attached to interpretations. No probabilistic uncertainty intervals for deterministic alternatives.

Map every substantive paragraph, table and caption to stable claims in `08_manuscript/claim_to_prose_map.md`, using unobtrusive paragraph comments/IDs if helpful. Keep the readable article free of review apparatus. Link every citation to a verified source entry/primary page. Local paths must resolve on this host. Missing benchmark/empirical results remain explicit informative placeholders tied to actual claim IDs and dependencies, with no guessed results.

Insert stable figure placeholders with relative brief anchors. Write `09_figures/figure_briefs.md`: a separate ID and complete brief for every figure, table-like visual, diagram and external image. Include claim IDs/purpose/position, what it cannot establish, exact v5 data paths/run IDs/fields, transformations/units/denominators/uncertainty, axes/panels/order/annotations/caption, status ready/planned/blocked, missing dependencies and filenames/formats. No map or external image is required. If proposing one, document geometry/join or original URL/creator/license/attribution/adaptation rights. Prefer a small adequate visual set. Ready quantitative figures must come from reviewed v5 values; conceptual schematics must be labelled conceptual. A blocked empirical comparison must stay blocked.

The visualization worker will make reproducible SVG and high-resolution PNG previews, editable code/plotting data and a visual-QA manifest. Once returned, integrate ready figures and finalized captions; retain informative blocked placeholders. Do a final prose-to-claims/captions check and report any scientific mismatch rather than repairing source claims yourself.
