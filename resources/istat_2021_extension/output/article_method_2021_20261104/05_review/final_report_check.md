Domain counts and reported PESO-weighted shares match the input audit. Changing the lowest schooling-category assumption materially changes the four shares and is reported. The 7,737 included households with younger children and the age-10 questionnaire routing are described correctly.

The regression fit indices, retained-row coefficients and conditional holdout summary agree with the checked outputs. Figure 7 is labeled apparent fit; separate scores identify the household holdout. No joint probability guarantee is asserted.
- All 22 examples in the H/E tables were matched programmatically to the corresponding 2021 cell, including each displayed group mean, sample SD and record count. The worked example, North West single-family A2, maps to H9 and E13 with means 11.11 h/day and 2,843 modeled appliance kWh/year. All 160 assignments in the report's editable Appendix table match the verified wide lookup. The category for ground, semi-basement or raised floors now names all three positions.

The first panel reflects the unavailable insulation rating by pooling its heating boxes. The source archive contains the relevant figure data and generating scripts. Layout is checked separately by the report author.

**Specific wording corrections sent to the author.** The first draft's “primary fits give equal weight to each household” is accurate for the clustering and empirical cell counts, but the polynomial actually weights its 21 windows equally. The total PFE cohort is 46,712 while only 12,334 households contribute to the 63 grid windows, so these counts deserve distinct labels. Finally only the loneliness and generation coordinates are min–max transformed within wave; the bounded education index enters directly. A short description of the uniform seeded age draws and 80–100 assumption for the oldest released band makes the reference to age assumptions self-contained. None of these clarifications changes a numerical result.

**Disposition.** The reported estimates, geographical lookup, equation, charts and scope pass the independent scientific check. File hashes and render/export checks at delivery are separate reproducibility tasks.
